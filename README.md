## 🎯 About This Project

Surreal Hub is a lightweight, Camp-only script for *Total Roblox Drama*. It was built from scratch with a focus on stability and clean design.

<table>
<tr>
<td width="50%" valign="top">

### ✅ What It Is

- 🎯 **Camp-only** — no wasted code
- ⚡ **Fast** — loads in under 3 seconds
- 🛡️ **Stable** — every callback is wrapped
- 🧹 **Clean** — proper module architecture
- 🔓 **Keyless** — no ads, no linkvertise

## 🛡️ Stability Promise

Surreal Hub was designed to **never crash the UI**.

| Guarantee | How It's Enforced |
|:----------|:------------------|
| **No callback crashes** | Every callback wrapped in `Utilities.safe()` |
| **No loop failures** | Every `RenderStepped` / `while` loop is `pcall`-guarded |
| **No notification spam** | All notifications capped at 4 seconds |
| **No dead references** | Every lookup is existence-checked |
